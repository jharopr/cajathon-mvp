# ClimaShield AI: centro de decisiones

Este documento prevalece sobre MASTER para la aplicación. La búsqueda inicial sugirió un sitio promocional de sostenibilidad; se descarta ese patrón porque la tarea es una consola de riesgo para analistas.

Dirección: cartografía operativa, evidencia visible y un recorrido claro desde amenaza hasta intervención. Un mapa amplio es la pieza dominante; alrededor, cifras sobrias y un panel de decisión.

Paleta: petróleo #102c35 para navegación, blanco #ffffff para superficies, gris frío #f3f6f7 para fondo, verde #147d64 para acciones, ámbar #9a5b08 para prioridad media, rojo #bc3d36 para prioridad alta. Texto principal #19333b y secundario #536771.

Tipografía: Segoe UI/system sans para lectura y cifras tabulares para montos; títulos de 30 px, cuerpo 16 px, etiquetas 14 px. Sin dependencia de fuentes externas.

Distribución: navegación lateral oscura de 232 px, cabecera compacta, mapa y lista de prioridades en proporción 2:1. En móvil, navegación horizontal y módulos apilados. Iconos Lucide coherentes, sin animaciones decorativas, controles con foco visible y estados de carga/error.

Principios: no mostrar indicadores inventados; distinguir datos sintéticos, pronóstico en vivo y escenario fijo. Las tablas permiten acceder al mismo contenido del mapa con teclado. Los gráficos nombran cada escenario y muestran el importe.
